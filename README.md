# GUESSTY — 게스티메이션 면접 도장깨기 게임

신입 지원자가 가상의 회사를 돌며 면접에서 게스티메이션(페르미 추정) 문제를 푸는 모바일 세로 픽셀 웹 게임입니다.
문제를 쪼개고, 가정하고, 계산하고, 결과를 복기하며 숫자로 판단하는 사고력을 연습합니다.

- 플레이: https://sy-02424.github.io/Guessty/
- 권장 환경: 모바일 세로 화면 (PC에서는 가운데 430px 게임 화면)

## 실행 방법

정적 HTML / CSS / 바닐라 JS 프로젝트입니다. 설치할 패키지는 없습니다.

1. 저장소 받기
   ```
   git clone https://github.com/sy-02424/Guessty.git
   ```
2. VS Code로 `Guessty` 폴더 열기
3. 확장 프로그램 **Live Server** 설치
4. `index.html` 오른쪽 클릭 → **Open with Live Server**

> 문제 데이터를 JSON으로 불러오기 때문에 `index.html`을 더블클릭으로 열면 동작하지 않습니다. 반드시 Live Server 같은 로컬 서버로 여세요.

## 게임 흐름

타이틀 → 인트로 → 맵 → 회사 선택 → 모드 선택(가이드 / 실전) → 1차 면접 → 통과하면 2차 면접 → 결과·복기

- 회사: 현재 3곳 (쟤당치킨 · 대충통운 · 촤지피티), `data/`에 회사·문제 파일을 추가해 늘릴 수 있음
- 판정: 최종 답과 실제 값의 배수(큰 값 ÷ 작은 값) 3배 이하 합격, 10배 이하 보류(통과), 그보다 크면 탈락
- 가이드모드: 공식 만들기 → 가정하기 → 계산 → 디테일을 선택지로 진행
- 실전모드: 직접 답을 입력하고, 끝난 뒤 모범 공식 공개
- 진행 기록은 브라우저 localStorage에만 저장되며 외부로 수집되지 않습니다

## 폴더 구조

```
index.html · css/ · js/        게임 화면
data/companies.json            회사 목록
data/problems/{회사id}.json     회사별 면접 문제 (chicken · delivery · it)
assets/                        픽셀 그림
docs/game-rules.md             게임 규칙
docs/data-schema.md            데이터 형식
.claude/skills/guessty-problem 문제 제작 스킬 + 자동 검사(check.py)
tools/                         그림 변환 스크립트 (Python · Pillow)
CLAUDE.md · DESIGN.md · COPY.md 작업·디자인·문구 규칙
```

## 문제 제작 방법

면접 문제는 Claude Code와 문제 제작 스킬로 만들었습니다.

```
/guessty-problem {회사id}
1차: {질문}
2차: {질문}
```

만든 문제 파일은 자동 검사로 형식을 확인합니다. (Python 3 필요)

```
python .claude/skills/guessty-problem/check.py data/problems/chicken.json
```

검사 항목: 공식 단계 순서, 선택지 색 구성, 오차 배수 범위, 대사 줄 수, 가정하기 선택지 숫자 노출, 모범 공식 3배 이내, 출처·기준연도 빈칸.
"통계·질문·공식이 같은 대상을 세는지"는 자동 검사로 확인할 수 없어 제작 순서에서 먼저 확인합니다.

## 그림 변환 (선택)

게임에 쓰는 그림(`assets/`)은 이미 들어 있어서 실행에는 필요 없습니다.
원본 시안을 픽셀 그림으로 다시 변환할 때만 사용합니다.

1. 패키지 설치 (Python 3)
   ```
   pip install -r tools/requirements.txt
   ```
2. 변환 실행
   ```
   python tools/convert.py
   ```

- 사용 라이브러리: Pillow (이미지 색 줄이기·크기 변환)
- 원본 시안(`assets/raw/`)은 저장소에 올리지 않아, 저장소만 받은 경우 변환은 실행되지 않습니다.
