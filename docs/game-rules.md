# 게임 규칙 요약 (면접·결과 화면 작업 때 읽기)

- 회사 상태: 잠김 / 진행 중 / 도장 완료
- 회사마다 1차·2차 면접, 면접마다 모드(가이드 / 실전) 선택
- 판정: 배수 = 큰 값 ÷ 작은 값 (최종 답 vs 실제 값). 3배 이내 합격 / 10배 이내 보류(통과) / 초과 탈락
- 경계: 이내 = 이하(3.0배는 합격, 10.0배는 보류). 최종 답이 0·음수·빈칸이면 제출을 막는다. (왜: 0으로 나누면 판정이 깨짐) → 검사: 실제 값 100에 300 / 1000 / 1001 / 0 입력 → 합격 / 보류 / 탈락 / 제출 막힘
- 도장: 2차까지 통과하면 획득, 모드 무관
- 재지원: 탈락한 면접부터, 같은 문제, 모드 다시 선택 가능
- 이탈: 면접 도중 나가면 그 면접 처음부터, 걸린 시간 초기화
- 가이드모드: 공식 만들기 노랑은 오차 배수를 최종 답에 곱함, 빨강은 공식 만들기 단계에서만 자진 퇴장
- 디테일: 합불·최종 답 영향 없음, 면접관 마지막 한마디·복기만 바뀜
- 노션 PRD는 내가 링크를 줄 때만 연다. 작업에 필요한 기준은 이 파일에 옮겨 적는다.
