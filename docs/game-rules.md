# 게임 규칙

## 1. 화면 흐름
- PRESS START(매번) → 인트로(첫 방문만) → 튜토리얼(첫 방문만, 오른쪽 위 SKIP) → 맵. 재방문하면 PRESS START 다음 바로 맵으로 간다.
- 인트로를 보고 나면 localStorage에 guessty_intro_seen을 저장한다.
- 맵에서는 회사를 탭·클릭해 들어간다. 주인공은 진행 중 회사 앞에 서 있고, 직접 조작해 걷지 않는다.

## 2. 면접·판정
- 회사 상태: 잠김 / 진행 중 / 도장 완료.
- 회사마다 1차·2차 면접이 있고, 면접마다 모드(가이드 / 실전)를 고른다.
- 배수 = 큰 값 ÷ 작은 값 (최종 답 vs 실제 값). 3배 이하 합격, 10배 이하 보류(통과), 그보다 크면 탈락.
- 최종 답이 0·음수·빈칸이면 제출을 막는다.
- 도장: 2차까지 통과하면 받는다(모드 무관).
- 재지원: 탈락한 면접부터 같은 문제로 다시 보고, 모드는 다시 고를 수 있다.
- 가이드모드: 공식 만들기에서 노랑을 고르면 그 선택지의 오차 배수를 최종 답에 곱한다. 빨강은 공식 만들기 단계에서만 자진 퇴장으로 끝난다. 디테일 선택은 합불·최종 답에 영향이 없고 면접관 마지막 한마디·복기만 바뀐다.
- 플레이 중에는 등급 색·배수·다른 효과음 같은 정답 힌트를 보여 주지 않고 결과·복기에서 공개한다. 예외: 가이드모드 면접관 표정(끄덕·갸웃), 빨강 자진 퇴장.
- 가이드모드 가정하기는 선택지에 근거만 보여 주고 숫자는 숨긴다. 고른 숫자는 3단계 계산 독백에서 처음 공개한다.

## 3. 선택·저장
- 선택은 되돌릴 수 없고, 연타해도 한 번만 인정한다.
- 저장은 localStorage guessty_ 키로 면접 단위로 한다. 면접 도중 나가면 그 면접을 처음부터 다시 하고 걸린 시간도 초기화한다.
